      How the decoder works

      It reads the list the way you would at the shelf. It splits the list at the commas, opens every bracket (a "recipe inside the recipe"), keeps each percentage, and checks each ingredient against a hand-written list of about 300 ingredient names, additive functions and E-numbers.

      • Sugar names are counted separately, because a recipe that uses several sugars can keep each one lower in the list. Learn the sugar names →
      • E-numbers are explained by their job: colour, preservative, emulsifier, raising agent and so on. A code is an identifier, not a verdict. E-numbers explained →
      • Processing clues follow the NOVA framework: ingredients and "cosmetic" additives (flavourings, colours, emulsifiers, sweeteners, thickeners and similar) that are rarely used in a home kitchen. The four NOVA groups →
      Please read: this is an educational estimate from words on a label, not a lab test, a health score or an allergen check. Labels can be incomplete, translated or abbreviated, and the decoder only knows the names in its list. NOVA describes processing, not nutrition. If you have an allergy or a medical diet, always read the pack itself and follow your doctor's advice.
