Les numéros E expliqués : comprendre le rôle de l’additif

Un numéro E est un identifiant, pas un avertissement automatique qui dirait qu’un aliment est mauvais pour la santé ou dangereux.

Que vous apprend le code ?

Il identifie un additif précis dans les systèmes qui utilisent l’étiquetage par numéros E. Pour comprendre pourquoi il est dans un produit, regardez sa fonction technologique : il peut aider à conserver, colorer, épaissir, régler l’acidité ou garder les ingrédients mélangés.

E300 — acide ascorbique : vitamine C ; utilisée comme antioxydant et dans certaines farines ou produits de boulangerie.

E330 — acide citrique : correcteur d’acidité ; c’est l’acide présent dans les agrumes, un exemple familier.

E440 — pectine : épaississant ou gélifiant, utilisé dans des produits comme les confitures.

E500 — bicarbonate de sodium : poudre à lever, plus connue sous le nom de bicarbonate de soude.

Lire les informations sur les additifs avec bon sens

Demandez-vous ce que fait l’additif, comment le produit est fabriqué dans son ensemble, et ce que montrent le reste de la liste d’ingrédients et le tableau nutritionnel. Certains additifs sont des substances familières ; d’autres ont des fonctions techniques précises. Le code seul n’est pas une évaluation complète de l’aliment.

L’autorisation réglementaire et les usages permis varient selon les pays et peuvent changer. Pour les questions juridiques ou de sécurité, adressez-vous à l’autorité de sécurité alimentaire de votre pays.
