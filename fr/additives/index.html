Un numéro E est un identifiant du système européen de numérotation des additifs. Il ne veut pas dire que l’additif est autorisé aujourd’hui dans tous les pays ou toutes les catégories d’aliments. Les règles varient selon les régions et peuvent changer : vérifiez la réglementation locale. Le code n’est pas une note de danger. Comment lire les numéros E sans s’affoler →
